Use a data element token such as %loggedIn%, or type a literal value.

Provide a value to convert.

Matching

Comma separated. Leave blank to use true, yes, y, 1, on, t.

Comma separated. Leave blank to use false, no, n, 0, off, f.

A value cannot appear in both the true and false lists.

Edge cases

Tags substitutes the data element's Default Value whenever this data element returns null or undefined. To send a real null to Adobe Experience Platform, choose Return null and leave the Default Value field on this data element empty.
